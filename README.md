# Fenómenos de Transporte — Interactivo

## Cómo abrir
1. Abre `index.html` en cualquier navegador moderno (no requiere servidor).
2. Usa el toggle **ES/EN** en la esquina superior derecha para cambiar el idioma.

## Cómo usar los módulos
- Ajusta sliders para ver **KPIs**, **gráficas** y **micro-explicaciones**.
- Prueba los **presets** para escenarios típicos.
- Completa los **mini-retos** (se validan en vivo y también se resumen al final).

> Nota: el sitio es completamente estático (HTML/CSS/JS + Chart.js).
